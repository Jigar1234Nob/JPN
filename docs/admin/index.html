Before launch

  • Host the proxy backend separately from GitHub Pages.
  • Use server-side login and admin roles, not a client-side password prompt.
  • Protect secrets with environment variables.
  • Rate-limit proxy use and block private, loopback and link-local destinations to prevent SSRF.
  • Test in a private staging environment before enabling public access.
