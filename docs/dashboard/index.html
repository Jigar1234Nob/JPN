Step-by-step setup

Before you start

You'll need access to the JPN configuration in Downloads. Install v2rayN first. You do not need Proxifier just to use a supported browser.

1. Install v2rayN

  1. Click Get v2rayN below to open the official download page.
  2. Choose the Windows version for your computer: ARM64 for your Snapdragon/Windows-on-ARM Surface, or x64 for most Intel or AMD computers.
  3. Download the ZIP file. In File Explorer, right-click it and choose Extract All, then click Extract.
  4. Open the extracted folder and run v2rayN.exe. If Windows shows a security warning, only continue if you downloaded it from the official v2rayN page.
Get v2rayN ↗

2. Download your JPN configuration file

  1. Return to the Downloads section near the top of this page.
  2. Find the JPN configuration download and click its download button. If no file is listed, the release has not been published to your account yet.
  3. Keep the downloaded .json file private. It is intended to be downloaded once and used on one device. Do not share it or copy it to another computer.

3. Import the JSON file into v2rayN

  1. Open v2rayN.
  2. Use its configuration import option and choose the JPN .json file you downloaded.
  3. When the new server/profile appears in the list, select it and click Set as active server if needed, then click Run/Connect (the wording can vary by version).
  4. Check that v2rayN shows a connected/running status before opening your browser.

The current download system does not technically block a second download or bind the file to one device yet. The one-download/one-device rule is currently a usage policy, not an enforced technical limit.

4. Choose how you want to use JPN

Simple browser setup: Keep v2rayN running and use Microsoft Edge on Windows ARM64 or x64. Google Chrome is supported for this browser-only setup on x64 Windows, not ARM64.

Optional: use Proxifier for more applications. This can route many desktop apps through v2rayN, but it is not a full-device VPN and some apps may not work with it.

Get Proxifier ↗

Proxifier setup, step by step

  1. Install and open Proxifier. Make sure v2rayN is already running and connected.
  2. In Proxifier, open Profile → Proxy Servers → Add.
  3. Enter Address 127.0.0.1, Port 10808, and choose SOCKS Version 5. Click OK. If you changed the SOCKS port in v2rayN, use that port instead.
  4. Run the proxy check if the option is available. It should succeed while v2rayN is connected.
  5. Open Profile → Proxification Rules and add a rule named All applications.
  6. Set Applications to Any, Target hosts to Any, Target ports to Any, and Action to the SOCKS5 proxy you just added. Move the rule above general/direct rules if needed, then save.
  7. Test one app first. If the internet stops working or local devices become unreachable, disable the All applications rule or change its Action to Direct, then check v2rayN and the proxy settings.

The all-applications rule is broad and may interrupt apps, local-network access, or sign-in tools. Keep it optional. It only redirects compatible connections handled by Proxifier; it does not guarantee that every part of Windows uses JPN.
